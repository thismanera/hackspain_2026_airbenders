# Imágenes de los casos de uso

Cada ficha indica qué capturar, qué información debe quedar visible y después
de qué párrafo insertar la imagen. Una captura debe demostrar una idea concreta,
no reproducir una pantalla completa sin jerarquía.

## Capturas mínimas

1. La comparación o contraste que plantea el caso.
2. La evidencia que explica la diferencia: bloques, cobertura, alertas o grupo.
3. La puerta y la decisión resultante.
4. El forecast o playbook solo cuando aporte una lectura distinta.

## Convención

```text
<numero>-<descripcion>.png
```

Ejemplos:

```text
01-comparacion.png
01-ficha-comp-0484.png
01-ficha-comp-0875.png
02-grupo-0217.png
02-ficha-comp-0512.png
02-ficha-comp-0926.png
03-comparacion.png
05-forecast-sombra.png
08-cortafuegos.png
```

Cada imagen debería tener una leyenda con empresa o grupo, mes y la lectura que
se quiere comprobar. Recorta navegación y espacios que no aporten información,
pero conserva los títulos necesarios para identificar la métrica. Evita datos
personales y no uses una captura de un run o mes distinto al de la ficha.
